# สูตรแนว "สร้างตึก" ภาพ 8-bit (Tower Stacker / Tower Tycoon)

มี 2 แบบ เลือกตามเวลาที่มี:
- **มินิในคลาส: ซ้อนตึก (Stacker)** — บล็อกชั้นใหม่แกว่งซ้าย-ขวา แตะเพื่อวาง ส่วนที่ยื่นเกินถูกตัดทิ้ง ซ้อนให้สูงที่สุด
- **เต็ม (ทำต่อที่บ้าน): ตึกธุรกิจ (Tycoon)** — สร้างชั้น จ้างคน รับแขก เก็บเงินอัปเกรด แบบ **Vibe Tower** (เกมตัวอย่าง ใช้เวลาทำหลายวัน)

## ภาพ 8-bit ให้คม (สำคัญ)
- ภาพพิกเซลใช้ `setOrigin` + ขนาดเป็นจำนวนเต็มเท่า (×2 ×3) · สร้าง texture เล็กแล้วขยายด้วย `.setScale()` และตั้ง `this.textures.get(key).setFilter(Phaser.Textures.FilterMode.NEAREST)` เฉพาะภาพพิกเซล
- **ตัวหนังสือห้ามเป็นพิกเซล** — ใช้ `text()` จาก juice.js (ฟอนต์ไทยคม) เสมอ (CEO ZenityX ทักเรื่องนี้)
- สีน้อย ๆ 8–16 สี คอนทราสต์สูง

## Stacker (มินิ)
- บล็อกแกว่งด้วย `x = cx + sin(t * SWING) * RANGE` · แตะ = วาง · ส่วนที่ไม่ซ้อนกับชั้นล่างถูกตัด (ตกลงมาเป็นเศษพร้อมหมุน)
- วางตรงเป๊ะ (คลาดไม่เกิน 4px) = **PERFECT!** ไม่ถูกตัด + คอมโบ + บล็อกขยายกลับนิดหน่อย
- ตึกสูงเกินครึ่งจอ → กล้องเลื่อนขึ้น (`this.cameras.main.scrollY` แบบ tween)
- ยิ่งสูงยิ่งแกว่งเร็ว · บล็อกหมด (กว้าง ≤ 0) = จบ
- คะแนน = ชั้น × 10 + PERFECT ×คอมโบ · FEVER: ชั้นทองคะแนน ×2
- เวลา: ไม่ต้องจับเวลา (จบเมื่อพลาด) → ตั้ง `GAME_TIME` สูง ๆ หรือปิดตัวจับเวลา

## Tycoon (เต็ม)
ชั้นแต่ละแบบ (คาเฟ่ ร้านเกม สตูดิโอ) ผลิตเงินต่อวินาที · แขกเดินเข้าลิฟต์ (ลากแขกไปชั้นที่ต้องการ = โบนัส) · อัปเกรดชั้น/จ้างพนักงาน · ภารกิจรายวัน · เซฟใน localStorage
→ อ่านสูตร idle ใน `genres/idle.md` ประกอบ

## config.js ที่ควรมี (Stacker)
`BLOCK_W 160` · `BLOCK_H 26` · `SWING 2.2` · `SWING_UP 1.04` (ต่อชั้น) · `PERFECT_PX 4` · `FLOOR_POINTS 10` · `PERFECT_BONUS 30` · GRADES

## AI เล่นเอง (?bot=1)
แตะเมื่อบล็อกห่างจากกึ่งกลางชั้นล่างไม่เกิน 6px (ใส่ความคลาดเคลื่อนสุ่ม ±5px ให้เหมือนคน)

# สูตรแนว "ยิงยานอวกาศ" (Shoot 'em up)

ยานผู้เล่นอยู่ล่างจอ ลากนิ้วเลื่อน **ยิงอัตโนมัติ** ศัตรูมาเป็นฝูง จบด้วยบอส
เกมตัวอย่าง: **Star Guardian** (3 เฟส + ยานแม่)

## ลูปหลัก
หลบกระสุน + จัดตำแหน่งยิงฝูง → เก็บอัปเกรดปืน → ปืนแรงขึ้นรู้สึกเก่งขึ้น → บอสตอนท้าย → ชนะ/แพ้

## การควบคุม
- **ลากนิ้ว = เลื่อนยาน** (ยกยานเหนือนิ้ว ~50px ให้มองเห็น) · ยิงเองทุก `FIRE_EVERY` ms → ผู้เล่นโฟกัสการหลบ
- ใช้ `onDrag()` (โครงแม่แบบส่ง pointermove มาให้แล้ว)

## ของในเกม
| ของ | พฤติกรรม |
|---|---|
| กระสุนผู้เล่น | ขึ้นตรง ๆ · อัปเกรด: 1 นัด → 2 นัดคู่ → 3 นัดกระจาย |
| ศัตรูเล็ก | มาเป็นฝูงตามรูปแบบ (แถวตรง · ตัว V · ส่ายซิกแซก) ไม่ใช่สุ่มเดี่ยว ๆ |
| ศัตรูยิงสวน | ยิงช้า ๆ ตรงไปหาผู้เล่น (ให้หลบทัน) |
| บอส | เลือดเยอะ มีหลอดเลือดบนจอ · เหลือครึ่งเลือด = โกรธ ยิงถี่ขึ้น |
| ดรอป | อัปเกรดปืน · หัวใจ · ดาวคะแนน |

## โครงด่าน (เฟส)
- เฟส 1 (0–15 วิ) ฝูงง่าย ไม่ยิง · เฟส 2 ฝูงยิงสวน · เฟส 3 บอส (แทน FEVER หรือพร้อม FEVER)
- เปลี่ยนเฟสด้วย `Juice.banner('เฟส 2!')`

## ความมันส์เฉพาะแนวนี้
- ศัตรูโดนยิง: กะพริบขาว (`setTintFill(0xffffff)` 50ms) · ระเบิด = `Juice.burst` ใหญ่ + เสียง hit เบา ๆ
- ฆ่าติดกัน = คอมโบ (ใช้ `addScore`) · บอสตาย = หยุดแว้บ 150ms + จอสั่นแรง + ประกายเต็มจอ
- ปืนอัปเกรด = banner "POWER UP!"

## config.js ที่ควรมี
`FIRE_EVERY 180` · `BULLET_SPEED 700` · `ENEMY_SPEED 120` · `WAVE_EVERY 2500` · `ENEMY_HP 1` · `BOSS_HP 60` · `BOSS_AT 20` (วินาทีที่บอสมา) · `ENEMY_SHOT_EVERY 1400` · คะแนน/คอมโบ/GRADES ตามแม่แบบ

## AI เล่นเอง (?bot=1)
เลื่อนยานไปใต้ศัตรูที่ใกล้ที่สุด · ถ้ามีกระสุนศัตรูในระยะ 120px เหนือยาน → หลบข้างที่ว่างกว่า

## มินิ vs เต็ม
- มินิ: ยิงอัตโนมัติ + ฝูง 3 รูปแบบ + อัปเกรดปืน 1 ขั้น + บอสง่าย
- เต็ม: เลือกยาน 3 ลำ · ความยาก 3 ระดับ · บอสหลายท่า · ด่านต่อเนื่อง

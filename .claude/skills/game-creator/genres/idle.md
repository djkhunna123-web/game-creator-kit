# สูตรแนว "เปิดร้าน / เลี้ยงสัตว์" (Idle Tycoon)

แตะเพื่อขาย/ดูแล ได้เงิน → ซื้ออัปเกรด → ร้านหาเงินเองตอนไม่ได้เล่น → กลับมาเก็บ
เกมตัวอย่าง: **Meow Café** (คาเฟ่แมว ใช้เวลาทำหลายวัน) — ในคลาสทำเวอร์ชันมินิ

## ลูปหลัก (ต้องรู้สึก "โตขึ้น" ทุก 30 วินาที)
แตะ → เงินเด้ง → ซื้อของชิ้นแรกได้เร็ว (ภายใน 20 วิ) → รายได้ต่อวินาทีขึ้น → ของชิ้นต่อไปแพงขึ้น ×1.15 → ปลดล็อกของใหม่ → ...

## มินิ (25 นาที)
- จอบน: ร้าน/ห้องเลี้ยง + ตัวละคร 1–3 ตัว (เดินไปมา) · ปุ่มใหญ่ "ขาย/ให้อาหาร" (แตะรัว ๆ ได้)
- จอล่าง: รายการอัปเกรด 4 อย่าง (ปุ่มสูง ≥ 56px) ราคาขึ้นทีละ ×1.15 · ซื้อไม่ได้ = ปุ่มจาง
- เงินต่อวินาทีเพิ่มจากอัปเกรด · ตัวเลขใหญ่ใช้ `1.2K 3.4M`
- **เซฟอัตโนมัติ** ใน localStorage ทุก 5 วิ + ตอนปิดหน้า · เปิดใหม่ = "ระหว่างที่ไม่อยู่ ร้านหาได้ 1,234!" (คำนวณจากเวลาที่หายไป สูงสุด 2 ชั่วโมง)
- ไม่มีชีวิต/เวลา → ใช้โครงแม่แบบแค่ HUD + ความมันส์ · ซ่อนตัวจับเวลา · ไม่ต้องหน้าเกรด
- ตารางคะแนน: ส่ง "เงินรวมทั้งหมด" ได้ แต่ต้องตั้ง `max_points_per_second` ตามรายได้สูงสุดจริง (แนวนี้โกงยาก กันได้ไม่ดี → ใช้แค่เล่นสนุก)

## ความมันส์เฉพาะแนวนี้
- แตะ = ตัวเลข +เงิน ลอย + ปุ่มยุบ-เด้ง + เสียงเหรียญไล่โน้ตตามความเร็วแตะ
- ซื้ออัปเกรด = ประกาย + ของใหม่โผล่ในร้านทันที (เห็นผลบนจอ ไม่ใช่แค่ตัวเลข)
- ลูกค้า/สัตว์มีอารมณ์ (♥ ลอย, ซูมเด้ง) · เหตุการณ์สุ่ม "ลูกค้า VIP!" แตะทันใน 5 วิ = ×5

## config.js ที่ควรมี
`TAP_VALUE 1` · `UPGRADES: [{ name, cost, perSec }, ...]` · `COST_GROWTH 1.15` · `OFFLINE_MAX_HOURS 2` · `VIP_EVERY 45000` · `SAVE_KEY`

## AI เล่นเอง (?bot=1)
แตะ 6 ครั้ง/วิ · ซื้ออัปเกรดที่คุ้มสุด (perSec/cost) เมื่อมีเงินพอ · วัดว่าซื้อของชิ้นแรกได้ใน ≤ 20 วิ และไม่ตันก่อน 3 นาที

## มินิ vs เต็ม
- มินิ: แตะขาย + อัปเกรด 4 อย่าง + รายได้อัตโนมัติ + เซฟ + เงินตอนไม่อยู่
- เต็ม: หลายห้อง/หลายสัตว์ · ภารกิจรายวัน · ตกแต่ง · กิจกรรมเทศกาล · ล็อกอินเซฟบนคลาวด์

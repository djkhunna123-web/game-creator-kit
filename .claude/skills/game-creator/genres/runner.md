# สูตรแนว "วิ่งไม่หยุด" (Endless Runner)

ตัวละครวิ่งเองไปทางขวา ผู้เล่นกระโดด/สไลด์ เก็บของ หลบสิ่งกีดขวาง ยิ่งวิ่งไกลยิ่งเร็ว
เกมตัวอย่าง: **Mochi Dash** (ในชุดสไลด์) — ห้ามลอกชื่อ/ตัวละคร/ด่านของเกมวิ่งดัง ๆ ให้ตั้งใหม่หมด

## เลือกแบบก่อน (2 แบบ)
| | แบบแตะ (แนวตั้ง) | แบบปุ่ม (แนวนอน) |
|---|---|---|
| เหมาะกับ | มินิในคลาส 25 นาที · คนเพิ่งเริ่ม | เกมวิ่งเต็มรูปแบบที่มีปุ่มกระโดด + ปุ่มสไลด์ |
| `ORIENTATION` | `'portrait'` (360×640) | `'landscape'` (640×360) + แก้ manifest (ดู `reference/mobile.md`) |
| ควบคุม | แตะจอ = กระโดด (2 ชั้น) | ปุ่มซ้าย = กระโดด · ปุ่มขวา = สไลด์ (สลับฝั่งได้ใน config) |
| สิ่งกีดขวาง | บนพื้น (กระโดด) | บนพื้น (กระโดด) + **ของห้อยด้านบน (ต้องสไลด์)** |

ผู้ใช้พูดถึง "ปุ่มกระโดด/สไลด์" หรือ "วิ่งแนวนอน" → แบบปุ่ม · ไม่ได้บอก → แบบแตะ
ค่าเริ่มต้นแบบปุ่ม: **กระโดดซ้าย · สไลด์ขวา** (ผู้ใช้ขอให้สลับได้ใน `JUMP_SIDE`)

## ลูปหลัก (สิ่งที่ทำให้สนุก)
วิ่ง → เห็นของ/สิ่งกีดขวางมาแต่ไกล → ตัดสินใจกระโดด/สไลด์ → เก็บเหรียญเป็นแถว (คอมโบ!) → เร็วขึ้นเรื่อย ๆ → FEVER

---

## แบบแตะ (แนวตั้ง 360×640)
- **แตะ = กระโดด** · แตะซ้ำกลางอากาศ = **กระโดด 2 ชั้น** (ครั้งเดียว) · ใช้ `onTap()` ใน game.js · แตะตอนนับถอยหลังไม่นับ
- พื้นอยู่ที่ y ≈ 520 · ตัวละครยืนที่ x ≈ 90 (อยู่ซ้าย เห็นของที่กำลังมา)
- ฟิสิกส์: `GRAVITY 1900` · `JUMP 720` · กระโดดรอบ 2 = `JUMP * 0.85`

## แบบปุ่ม (แนวนอน 640×360)
### ปุ่ม
- วงกลม 76px ห่างขอบ 18px · โปร่ง 55% · **ไอคอนลูกศรล้วน ไม่มีตัวหนังสือ**: ⬆ ขาวบนวงชมพู = กระโดด · ⬇ ขาวบนวงฟ้า = สไลด์
- ฝั่งของปุ่มตั้งใน config: `JUMP_SIDE: 'left'` (กระโดดซ้าย สไลด์ขวา — แบบ Mochi Dash) หรือ `'right'`
- หน้าเริ่มสอนด้วยไอคอน: การ์ด [ปุ่ม] ▶ [ท่าตัวละคร] + คำสั้น ๆ ("กดซ้ำ = 2 ชั้น" / "กดค้าง") เรียงซ้าย-ขวาตรงกับปุ่มจริง · ยกปุ่มจริงที่มุมจอขึ้นมาให้เห็นตอนหน้าเริ่ม
- กดแล้วย่อ 0.92 + สว่างขึ้น + เสียงคลิก (`Sfx.tick()`)
- **โซนแตะใหญ่กว่าปุ่ม**: แตะครึ่งจอฝั่งปุ่มกระโดด = กระโดด (`JUMP_ZONE: 0.5`) · อีกฝั่ง = สไลด์ · รองรับ 2 นิ้ว (`this.input.addPointer(2)`)
- คีย์บอร์ด: Space / ↑ / W = กระโดด · ↓ / S = สไลด์ (กดค้างได้) · เมาส์: คลิกฝั่งเดียวกับปุ่ม

### ท่าการเคลื่อนไหว
- **กระโดด**: กด = `vy = -JUMP` · กดซ้ำกลางอากาศ = ชั้น 2 (`JUMP2`, หมุนตัว 1 รอบ) · **ปล่อยปุ่มตอนยังลอยขึ้น = ตัดแรงครึ่งหนึ่ง** (กระโดดเตี้ย คุมง่าย) — ตัดหลังกดอย่างน้อย 0.1 วิ แตะเร็วแค่ไหนก็ยังข้ามลังได้ (Mochi Dash: เตี้ย ~72px · เต็ม ~111px)
- กดกระโดดก่อนถึงพื้นนิดเดียว (≤ 0.13 วิ) = กระโดดทันทีที่ลง (jump buffer) · ลุกจากสไลด์แล้วกระโดดได้เลย
- **สไลด์**: กดค้าง = ตัวเตี้ยครึ่งหนึ่ง (กล่องชนเตี้ยลง) · แตะสั้นก็สไลด์อย่างน้อย 0.35 วิ · ฝุ่น/ประกายที่พื้น · ปล่อยตอนยังอยู่ใต้ของห้อย = สไลด์ต่อให้เองจนพ้น (ไม่โดนเพราะลุกเร็ว)
- **กดสไลด์กลางอากาศ** = ดิ่งลงเร็ว (`vy = DIVE`) แล้วสไลด์ต่อทันทีที่ถึงพื้นถ้ายังกดค้าง
- จอ 360 สูงไม่มาก: ความสูงกระโดด 2 ชั้นรวมต้องไม่ทะลุ HUD — คำนวณ `สูงสุด = JUMP² / (2 × GRAVITY)`

### โลก (หน่วยเกม)
- พื้นที่ y ≈ 268 (ใต้พื้นเป็นแถบดิน/ถนน ~90px ที่ปุ่มวางทับได้) · ตัวละครยืน x ≈ 170 (ปุ่มซ้ายอยู่มุม ไม่ทับตัวละคร · ตอนกระโดด 2 ชั้นไม่ทับคะแนนมุมซ้ายบน)
- ของสูงสุดที่ต้องเก็บได้ (ทองบนฟ้า) อยู่ต่ำกว่า HUD (y > 60) · HUD ใส่ขอบเข้ม (`stroke`) ให้อ่านออกบนฉากที่มีลาย
- ตัวเลขคะแนนของเหรียญธรรมดาให้เล็กและลอยสูงกว่าเหรียญ (ไม่บังหน้าตัวละครตอนเก็บเป็นแถว)
- **ฉากเลื่อนซ้อน 3 ชั้น** (parallax): ฟ้า/ของไกล ×0.1 · ตึก/แผงร้านกลาง ×0.45 · พื้น ×1.0 ของความเร็ววิ่ง — ใช้ `tileSprite` แล้วเลื่อน `tilePositionX`

### ท่าทางตัวละคร (ทุกสถานะมีกล่องชนของตัวเอง)
| สถานะ | ภาพ | ขยับด้วยโค้ด (ฟรี) | กล่องชน |
|---|---|---|---|
| วิ่ง | 4–6 เฟรมสลับ | เด้งขึ้นลงตามก้าว · เอนไปหน้าตามความเร็ว | สูงเต็ม |
| กระโดดขึ้น / ตก | 1 ภาพต่อท่า | ยืดตัวตอนขึ้น | สูงเต็ม |
| กระโดดชั้น 2 | ภาพกระโดด | หมุน 360° | สูงเต็ม |
| สไลด์ | 1 ภาพ | ฝุ่นที่พื้น | **เตี้ยครึ่งหนึ่ง** |
| ลงพื้น | ภาพวิ่ง | ยุบตัว (squash) 80 ms + ฝุ่น | สูงเต็ม |
| โดน | ภาพโดน | กระพริบ + อมตะ 1 วิ | — |
ยังไม่มีภาพ: วาดรูปทรง + ขยับด้วยโค้ดตามตารางก็ดูวิ่งได้แล้ว (ภาพใส่ทีหลังด้วย key เดียวกัน)

## ของในเกม
| ของ | พฤติกรรม | ผลตอนชน |
|---|---|---|
| เหรียญ/ขนม | วางเป็นแถว/โค้ง (ตามเส้นกระโดด) | `addScore(POINTS)` |
| ของทอง | หายาก ลอยสูง ต้องกระโดด 2 ชั้นถึง | `addScore(GOLD_POINTS, …, true)` |
| สิ่งกีดขวางต่ำ (ลัง) | ตั้งบนพื้น · ลังซ้อน = ต้องกระโดด 2 ชั้น | `loseLife()` + กระพริบอมตะ 1 วิ |
| **ของห้อย** (แบบปุ่ม) | ห้อยจากด้านบน ขอบล่างสูงกว่าพื้นนิดเดียว — ยืน/กระโดดชน · **สไลด์ลอดได้** (ราวโคมไฟ · ป้ายผ้า · ว่าวบินต่ำ) | `loseLife()` |
| ไอเทม | แม่เหล็ก (ดูดเหรียญ 5 วิ) · โล่ · บูสต์ (วิ่งเร็วชนทะลุ 3 วิ) | banner + เสียง power |
- **เฉียด!**: ข้ามลังแบบเท้าห่าง ≤ 12px หรือสไลด์ลอดของห้อยแบบกดช้าเกือบไม่ทัน → `Juice.banner('เฉียด!')` + โบนัส (นับคอมโบ)

**สร้างเป็น "ท่อน" (chunk)** ไม่สุ่มทีละชิ้น: เตรียม 8–12 แบบ แล้วสุ่มต่อกัน → เล่นแล้วรู้สึกออกแบบมา ไม่มั่ว · ต้องมีทางผ่านเสมอ
| ระดับ | ตัวอย่างท่อน |
|---|---|
| ง่าย (0–20 วิ) | ลังเดี่ยว + เหรียญโค้งข้าม · ของห้อยเดี่ยว (สไลด์) + เหรียญแถวล่าง · เหรียญแถวยาวบนพื้น |
| กลาง (20–40 วิ) | ลัง → ของห้อย ห่าง 1 จังหวะ · ลังซ้อน + เหรียญบนอากาศ · ว่าว 2 ตัว · ลัง 2 ใบห่าง ≥ 280px |
| ยาก (40 วิ+) | ของห้อย → ลัง → ของห้อย ติดกัน · ทองบนสุดต้องกระโดด 2 ชั้นแล้วสไลด์ทันทีที่ลง |
| FEVER | ฝนเหรียญ · ไม่มีสิ่งกีดขวาง 3 วิแรก |
(แบบแตะใช้เฉพาะท่อนที่ไม่มีของห้อย)
- ระวัง: ที่ความเร็วสูง กระโดดเต็มแรงลอยไกล ~0.64 วิ × ความเร็ว — ลังที่ห่างน้อยกว่านั้นต้องกระโดดเตี้ยหรือ 2 ชั้น (เป็นทักษะได้ แต่ด่านง่ายห้ามมี)

## ความยาก
- `RUN_SPEED` เริ่ม ~280–300 แล้วคูณ `SPEED_UP` ทุก 5 วิ (มีเพดาน `MAX_SPEED`) · ช่วงห่างของท่อนลดลงตามเวลา
- 3–5 วินาทีแรกไม่มีสิ่งกีดขวาง (ให้ตั้งตัว) · ท่อนยากออกตามเวลาที่รอด (ตารางด้านบน)

## ความมันส์เฉพาะแนวนี้
- ยืด-หดตอนกระโดด/ลงพื้น · ฝุ่นตอนลงพื้นและตอนสไลด์ (`Juice.burst` สีพื้น)
- เหรียญเรียงเป็นแถว = เสียงไล่โน้ตขึ้นเรื่อย ๆ (มีใน `addScore` แล้ว)
- ชนแล้วตัวกระเด็นนิดหน่อย + จอสั่น · ใกล้จบนับถอยหลังติ๊ก · บูสต์ = เส้นความเร็ว + ไฟท้าย (`Juice.trail`)

## config.js ที่ควรมี
- แบบแตะ: `GAME_TIME 45` · `LIVES 3` · `RUN_SPEED 260` · `SPEED_UP 1.07` · `GRAVITY 1900` · `JUMP 720` · `CHUNK_GAP 260` · `POINTS 10` · `GOLD_POINTS 50` · `POWER_EVERY 9000`
- แบบปุ่ม (ค่าจริงของ Mochi Dash v2): `ORIENTATION 'landscape'` · `GAME_TIME 60` · `RUN_SPEED 300` · `SPEED_UP 1.06` · `MAX_SPEED 540` · `MID_AT 20` · `HARD_AT 40` · `GROUND_Y 268` · `HERO_X 170` · `GRAVITY 2200` · `JUMP 700` · `JUMP2 560` · `JUMP_CUT 0.5` · `DIVE 950` · `SLIDE_MIN 0.35` · `STAND_H 54` · `SLIDE_H 28` · `HANG_GAP 38` · `NEAR_PX 12` · `BOOST_TIME 3` · `BUTTON 76` · `JUMP_SIDE 'left'` · `JUMP_ZONE 0.5`
- คอมโบ/FEVER/GRADES ตามแม่แบบ

## AI เล่นเอง (?bot=1)
- ให้บอทกดผ่านทางเดียวกับนิ้ว (`hold`/`unhold`) ปุ่มบนจอจะขยับด้วย
- **ลัง**: กระโดดเมื่อขอบลังห่าง `speed × 0.17` (ลังถัดไปใกล้ = กระโดดเตี้ย กดช้าลงเป็น `× 0.12`) · **ลังซ้อน**: กดเร็วขึ้น `× 0.26` แล้วกดชั้น 2 ตอน `vy > -170` · **ของห้อย**: กดสไลด์ค้างเมื่อห่าง `× 0.22` (ลอยอยู่ `× 0.34` = ดิ่งลง) จนพ้น · ทองบนฟ้า = กระโดด 2 ชั้น · ปล่อยปุ่มกระโดดตอนถึงจุดสูงสุด
- สุ่มจังหวะคลาดเคลื่อนต่อชิ้น + พลาดตั้งใจ ~5% จะได้คะแนนแบบคน · ถ้าบอทตายที่ชิ้นเดิมบ่อย ๆ = ด่านหรือจังหวะผิด (จดว่าตายเพราะอะไร แล้วแก้)
- วัดคะแนน 20 รอบ → ตั้ง GRADES · บอทไม่ตาย (`CONFIG.LIVES = 999`) → แต้มสูงสุด/วินาที × 1.2 = `max_points_per_second`

## มินิ (ในคลาส 25 นาที) vs เต็ม
- มินิ: แบบแตะ · กระโดด 2 ชั้น + เหรียญ + สิ่งกีดขวาง 2 แบบ + ท่อน 4 แบบ + ความมันส์ขั้นต่ำ
- เต็ม: แบบปุ่มแนวนอน · สไลด์ + ของห้อย · ท่าทางครบ · ไอเทม 3 แบบ · ท่อนแยก 3 ระดับ · ฉากซ้อน 3 ชั้น

# สูตรแนว "เล่นออนไลน์กับเพื่อน" (Party Game · จอใหญ่ + มือถือ)

ทุกคนในห้องเล่นพร้อมกัน: จอใหญ่ 1 จอ (โปรเจกเตอร์/ทีวี) เป็นเวที · มือถือทุกคนเป็นจอย
**อย่าเริ่มจากแม่แบบเกมนี้** — ใช้แม่แบบ **ห้องเล่นออนไลน์** (repo `online-room` · ตัวอย่างจริง https://online-room.zenityx-vibe.workers.dev)
แม่แบบมีครบ: รหัสห้อง + QR · Presence รายชื่อ · ห้องรวมพล (ตัวละครขยับสด) · แข่งกดรัว · ควิซสด · ผู้เล่นจำลองไว้ซ้อม (`npm run bots`)

## หลักการ (ต้องทำตาม)
- Supabase Realtime 2 ช่อง/ห้อง: `down` (จอใหญ่ → ทุกคน + Presence) · `up` (มือถือ → จอใหญ่ ส่งแบบไม่ subscribe)
- **จอใหญ่เป็นกรรมการ**: คิดคะแนน จับเวลา ตรวจความเร็วเอง · มือถือส่งแค่ "สิ่งที่ทำ"
- ส่งข้อความน้อย ๆ: ขยับ ≤ 6 ครั้ง/วินาที · ยอดกดส่งเป็นยอดรวมทุก 150ms · จอใหญ่ส่งสถานะซ้ำทุก 2 วิ
- แพ็กเกจฟรี: 200 คนพร้อมกัน · 2 ล้านข้อความ/เดือน (คลาส 8 คน 1 ชั่วโมง ≈ 40,000)

## ไอเดียที่ทำต่อจากแม่แบบได้ใน 60 นาที
| เกม | จอใหญ่ | มือถือ |
|---|---|---|
| แข่งกดรัวทั้งห้อง (มีแล้ว) | เชือกชักเย่อ 2 ทีม | ปุ่มใหญ่สีทีม |
| ตอบคำถามแข่งสด (มีแล้ว) | คำถาม + เฉลย + อันดับ | 4 ปุ่มสี ▲◆●■ |
| วิ่งแข่งพร้อมกัน | ตัวละครทุกคนบนลู่ · ใครถึงเส้นชัยก่อน | กดรัว/เขย่า = วิ่ง |
| วาดให้เพื่อนทาย | ภาพที่วาดขึ้นจอ · ใครทายถูกก่อนได้แต้ม | คนวาด: กระดาน · คนทาย: พิมพ์คำตอบ |
| โหวตสด | กราฟแท่งขยับสด | ปุ่มตัวเลือก |

## ตัวอย่างคำสั่ง
```
/game-creator อยากได้เกมแนวเล่นออนไลน์กับเพื่อน
จากแม่แบบห้องเล่นออนไลน์ ทำเกม "วิ่งแข่งเต่า" ทุกคนกดรัวให้เต่าวิ่ง ใครถึงเส้นชัยก่อนชนะ จอใหญ่โชว์ลู่วิ่ง
```

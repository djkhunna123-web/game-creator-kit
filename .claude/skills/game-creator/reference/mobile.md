# กฎมือถือ (ทดสอบที่จอ 375 × 812 · เกมแนวนอนทดสอบ 812 × 375 และ 915 × 412)

## ทิศจอ — เลือกครั้งเดียวตอนออกแบบ
| | แนวตั้ง (ค่าเริ่มต้น) | แนวนอน |
|---|---|---|
| ใช้กับ | **ทุกแนวเกม** (แตะ · เก็บของ · ยิงยาน · ตึก · เปิดร้าน · ออนไลน์) | **เฉพาะเกมวิ่งแบบมีปุ่มกระโดด + ปุ่มสไลด์** (`genres/runner.md` แบบแนวนอน) |
| `config.js` | `ORIENTATION: 'portrait'` | `ORIENTATION: 'landscape'` |
| จอเกม `W × H` | 360 × 640 | 640 × 360 |
| `manifest.webmanifest` | `"orientation": "portrait"` | `"orientation": "landscape"` (แก้ให้ตรงกับ config) |

- พิกัดเกมใช้ `W`, `H` จาก juice.js เสมอ — **ห้ามเขียน 360 / 640 ตรง ๆ** (เปลี่ยนทิศแล้วของจะหลุดจอ) · เกมขยายเต็มจอเอง ตัวหนังสือคมเพราะเรนเดอร์ละเอียด `Z` เท่า (อย่าเปลี่ยนส่วนนี้)
- ถ้าผู้เรียนไม่ได้ขอเกมวิ่งแบบมีปุ่ม → ใช้แนวตั้ง ไม่ต้องถาม

## ตัวหนังสือ
- ใช้ `text(ขนาด, สี)` เสมอ · ขนาด ≥ 15px · ห้ามใช้ฟอนต์พิกเซลกับภาษาไทย
- `text()` วัดความสูงด้วยตัวอย่างที่มีวรรณยุกต์ซ้อน (`เพื่อ` `ที่นี่` `ปู่`) แล้ว — ถ้าสร้างสไตล์ตัวหนังสือเอง ให้ส่งผ่าน `text()` ไม่งั้นวรรณยุกต์ด้านบนโดนตัดหาย

## แนวตั้ง
- ปุ่ม/เป้าแตะ ≥ 44px · ห่างกันพอ · ปุ่มสำคัญอยู่ครึ่งล่างจอ (นิ้วโป้งเอื้อมถึง)
- ลากนิ้ว: ยกตัวละครเหนือนิ้ว ~50px · ห้ามให้นิ้วบังของสำคัญ
- HUD อยู่ใน 60px บน · ข้อความยาวต้องไม่เกินกว้าง 320px (ใช้ `wordWrap`)

## แนวนอน (เพิ่มจากแนวตั้ง)
- **ถือ 2 มือ นิ้วโป้งซ้าย-ขวา**: ปุ่มอยู่ **มุมล่างซ้าย** และ **มุมล่างขวา** · ปุ่มกลม ≥ 64px (เกมวิ่งใช้ 76px) ห่างขอบ 18–24px
- ปุ่มเป็น **ไอคอนล้วน** (ลูกศร/รูป) สีต่างกันชัด ไม่ต้องมีตัวหนังสือในปุ่ม · สอนวิธีกดที่หน้าเริ่มด้วยไอคอน + คำสั้น ๆ
- **พื้นที่แตะจริงใหญ่กว่าปุ่ม**: แบ่งจอซ้าย/ขวาเป็นโซนกด (เช่น ซ้าย 40% / ขวา 60%) นิ้วไม่ต้องเล็งปุ่ม
- **2 นิ้วพร้อมกัน**: ใน `create()` ใส่ `this.input.addPointer(2)` · ใช้ `pointerdown` / `pointerup` แยกตาม `pointer.id` (กดค้าง + ปล่อย)
- **ขอบจอมีรอยบาก**: HUD และปุ่มเว้นขอบ ≥ 24px (มือถือยาว ๆ จะมีแถบดำซ้าย-ขวาให้อยู่แล้ว แต่จอ 16:9 ไม่มี)
- HUD อยู่ใน 48px บน · ปุ่มต้องไม่ทับ HUD และไม่บังตัวละคร (ตัวละครยืนกลางจอค่อนซ้าย ปุ่มอยู่มุมล่าง)
- หน้าเริ่ม/หน้าจบในแม่แบบจัดให้เองแล้ว (กล่องกลางจอ · หน้าจบเกรดซ้าย-คะแนนขวา)
- **หน้า "หมุนมือถือ"** + **หยุดเกมตอนจอตั้ง** + **Android แตะครั้งแรก = เต็มจอ + ล็อกแนวนอน** — juice.js ทำให้เองเมื่อ `ORIENTATION: 'landscape'` (iPhone ล็อกจอจากเว็บไม่ได้ จึงขึ้นหน้าบอกให้หมุนแทน)
- คีย์บอร์ดไว้ทดสอบบนคอม: Space / ↑ / W = กระโดด · ↓ / S = สไลด์
- หน้า "หมุนมือถือ" ขึ้นเฉพาะมือถือ/แท็บเล็ต (`pointer: coarse`) · คอมหน้าต่างแคบเห็นเกมย่อพอดีหน้าต่าง
- ฉากหลังแนวนอน: ภาพกว้าง 1280×720 (หรือแถบยาวต่อซ้าย-ขวาได้สำหรับเลื่อน)

## ทั่วไป
- เสียง: เล่นหลังแตะครั้งแรก · ไม่มีไฟล์เสียงก็ต้องมีเสียง (ระบบ `Sfx` สร้างเสียงเอง)
- ภาพ: ย่อให้เล็ก (ตัวละคร ~200px, ฉากหลัง 720×1280 หรือ 1280×720 jpg) รวมไม่เกิน ~2 MB โหลดเร็วบนเน็ตมือถือ
- ติดตั้งเป็นแอป: มี `manifest.webmanifest` + `sw.js` + ไอคอนแล้ว — เปลี่ยนชื่อ/ไอคอนให้ตรงเกม (`public/icons/` 192, 512, 180px)
  - Android Chrome: เมนู ⋮ → "ติดตั้งแอป" · iPhone Safari: ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

# เอฟเฟกต์พิกเซลสำเร็จรูป — pixelfx (ฟรี 244 แบบ · MIT)

ใช้เมื่อ: เกมภาพพิกเซล/8-bit หรือผู้ใช้อยากได้ "เอฟเฟกต์แบบเกม" (ระเบิด POW! เหรียญหมุน ฟันดาบ เลเวลอัป ไฟ น้ำแข็ง ฟ้าผ่า เวทมนตร์ ฝน หิมะ)
ไม่ต้องเจนภาพ ไม่ใช้เครดิต ZenityX Studio — ไลบรารีวาดด้วยโค้ดแล้วส่งออกเป็นสไปรต์ชีต (PNG + JSON) ให้ Phaser เล่น

## 1 · ติดตั้ง (ครั้งแรกครั้งเดียว) — วางไว้ "ข้าง" โปรเจกต์ ไม่ใช่ใน public/
```
git clone https://github.com/patch-gg/pixelfx ../pixelfx
```
บอกผู้ใช้ก่อนดาวน์โหลด · คำสั่งทั้งหมดด้านล่างรันในโฟลเดอร์ `../pixelfx`

## 2 · หาเอฟเฟกต์ที่ใช้ได้ก่อน (อย่าสร้างใหม่ถ้ามีของใกล้เคียง)
```
node tools/list.mjs coin          # ค้นจากชื่อ แท็ก คำอธิบาย
node tools/render.mjs explosions/cartoon-pow    # ได้ records/<id>/contact.png
```
**เปิดดู `contact.png` เองทุกครั้ง** ก่อนเลือก (ภาพรวมทุกเฟรม) · รายชื่อทั้งหมด: `docs/CATALOG.md` · แกลเลอรีออนไลน์: https://patch-gg.github.io/pixelfx
เอฟเฟกต์ที่ขึ้นป้าย `actor` ออกแบบให้เล่นกับตัวละคร — ส่งออกด้วย `--no-actor` แล้วตรวจภาพว่ายังดูดีไหม

| เหตุการณ์ในเกม | เอฟเฟกต์ที่ทดสอบแล้ว (id) | หมายเหตุ |
|---|---|---|
| ของหายาก / ไอเทมลอย | `pickups/coin-spin` (วนซ้ำ 56×56) | ใช้แทนรูปเหรียญได้เลย |
| ศัตรูตาย → เหรียญกระจาย | `spawn/coin-drop` | |
| เปิดหีบรางวัล | `pickups/chest-open` | ยาว 4.6 วิ ใช้ตอนจบ/รางวัลใหญ่ |
| โดนตี / ชน | หมวด `impacts` เช่น `impacts/hit-spark` `impacts/crit-hit` `impacts/hit-flash` | สั้น เล่นบ่อยได้ |
| คอมโบใหญ่ / บอสโดน | `explosions/cartoon-pow` (1 วิ) | คู่กับ `Juice.shake()` |
| ระเบิดพลังงาน | `explosions/plasma-explosion` | |
| ชนะ / ฉลอง | `explosions/firework-burst` | |
| ฉากหลังมีชีวิต | `fire/campfire` (วนซ้ำ) · หมวด `weather` `critters` | |
| เก็บเหรียญเข้าแถบคะแนน | `ui/coin-collect` | **มีตัวเลข ×12 อยู่ในภาพ** — ใช้เฉพาะตอนไม่มี HUD ซ้อน |

## 3 · เปลี่ยนสีให้เข้าธีมเกม (คำสั่งเดียว)
```
node tools/render.mjs fire/campfire --opts "{\"palette\":[\"#0c1430\",\"#1f4f94\",\"#58b4ec\",\"#d8f4ff\",\"#ffffff\"]}"
```
palette เรียงสี **เข้ม → สว่าง** (3–7 สี) · `--seed N` = สุ่มลายใหม่ · ใช้สีหลักของเกมจาก `config.js`
(บน PowerShell/CMD ต้องใส่ `\"` แบบด้านบน · บน Mac/Linux ใช้ `'{"palette":[...]}'` ได้)

## 4 · ส่งออกเข้าเกม
```
node tools/render.mjs explosions/cartoon-pow --sheet --bg none --no-actor --out ../<เกม>/art-src/fx
```
ได้ `<id>/cartoon-pow.png` (พื้นใส) + `cartoon-pow.json` → คัดลอกทั้ง 2 ไฟล์ไป `public/assets/fx/`
ส่งออกทั้งหมวด: ใส่ชื่อหมวดแทน id (เช่น `impacts`) — แต่ **เอาเข้าเกมเฉพาะตัวที่ใช้จริง** (ไฟล์ใหญ่ได้ถึง 1–2 MB/ตัว)
เช็กขนาด: แต่ละไฟล์ควร ≤ 300 KB · ใหญ่กว่านี้ให้เลือกตัวที่สั้นกว่า หรือ `--fps 15` ลดจำนวนเฟรม

## 5 · เล่นในเกม (แม่แบบรองรับแล้ว)
`public/config.js`:
```js
window.FX = { pow: 'assets/fx/cartoon-pow', hit: 'assets/fx/hit-spark', coin: 'assets/fx/coin-spin' };
```
`public/game.js` (ในส่วน ★ เปลี่ยนตรงนี้):
```js
this.playFx('pow', x, y);                         // เล่นครั้งเดียวแล้วหายเอง
this.playFx('pow', x, y, { scale: 2 });           // ใหญ่ขึ้น (ใช้เลขเต็ม พิกเซลจะคม)
const fire = this.playFx('coin', x, y, { loop: true });  // วนซ้ำ · ลบเองด้วย fire.destroy()
```
- แม่แบบโหลด `FX` ทั้งหมดอัตโนมัติ สร้างแอนิเมชันตาม fps/loop ใน JSON และตั้งจุดยึด (pivot) ให้ตรงกับที่ pixelfx ออกแบบ (เช่น ฐานกองไฟ = x,y)
- พิกเซลคมไม่เบลอ (ตั้ง NEAREST ให้เฉพาะเอฟเฟกต์ ไม่กระทบภาพอื่นในเกม)
- **ใช้คู่กับ juice.js ไม่ใช่แทน**: `addScore()` ยังต้องมีเสียง + ตัวเลขลอย · เอฟเฟกต์ใหญ่ (POW ระเบิด) ใช้กับเหตุการณ์สำคัญ ไม่ใช่ทุกเหรียญ — เหมือนกฎจอสั่นใน `juice.md`

## 6 · สร้างเอฟเฟกต์ใหม่ (เมื่อไม่มีของใกล้เคียงจริง ๆ)
ไลบรารีมีสกิล `skills/pixelfx` สอนวิธีแบบนักวาดพิกเซล: ร่าง → เรนเดอร์ → **เปิดดู contact.png** → แก้ อย่างน้อย 3 รอบ
- เปิดเซสชันใหม่ในโฟลเดอร์ `../pixelfx` (สกิลอยู่ในนั้น) หรือติดตั้งเป็นปลั๊กอิน `/plugin marketplace add patch-gg/pixelfx` → `/plugin install pixelfx@pixelfx` (**ถามผู้ใช้ก่อนติดตั้ง**)
- คำสั่งตัวอย่าง:
```
ใช้สกิล pixelfx สร้างเอฟเฟกต์ใหม่ ตอบเป็นภาษาไทย
เอฟเฟกต์: (เช่น ดาวระเบิดตอนได้คอมโบ ×5)
การเคลื่อนไหว: (ลอยหมุน / ระเบิดออกแล้วจางหาย / วนซ้ำ)
สีหลัก: (รหัสสีของเกม)
ใช้ที่ไหน: เกม Phaser บนมือถือ
ข้อกำหนด: หาของเดิมในไลบรารีก่อน · ถ้าสร้างใหม่ให้แก้ ≥ 3 รอบ บอกว่าแต่ละรอบแก้อะไร · รัน node tools/check.mjs ให้ผ่าน · ส่งออก --sheet --bg none
```
- ผลงานใหม่ต้องเป็นของใหม่ (ห้ามเลียนเอฟเฟกต์/โลโก้ของเกมดังที่มีลิขสิทธิ์)

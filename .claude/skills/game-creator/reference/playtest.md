# ให้ AI เล่นทดสอบเอง (ขั้นที่ 4)

## 1) ทำ bot
เติม `botPlay(time)` ใน game.js ให้เล่นแบบ "คนพอใช้ได้" (ไม่เก่งเกินจริง): จังหวะตอบสนอง ~250ms · ตัดสินใจจากของที่อยู่บนจอเท่านั้น
เปิดดู: `http://localhost:8100/?bot=1` · วัดเพดานคะแนน: ในคอนโซลพิมพ์ `CONFIG.LIVES = 999` (เล่นไม่ตาย)

## 2) รันหลายรอบแบบเร่งเวลา (ในเบราว์เซอร์ของ AI)
```js
// วางในคอนโซลของหน้า ?bot=1 — เดินเกมเร็วที่สุด เก็บผลใน window.__runs
let t = performance.now(); window.__runs = [];
while (__runs.length < 10) for (let i = 0; i < 600; i++) { t += 16.67; __game.step(t, 16.67); }
__runs.map(r => r.score)
```
ตอนเร่งเวลา ตัวหนังสือ/แอนิเมชันจะค้าง (tween ใช้นาฬิกาจริง) — วิธีนี้ใช้วัดตัวเลขเท่านั้น
ดูภาพจริง (แท็บที่ถูกซ่อนเกมจะหยุด) ให้เดินเกมด้วยเวลาจริง:
```js
let l = performance.now(); window.__pump = setInterval(() => { const n = performance.now(); __game.step(n, n - l); l = n; }, 16);
```

## 3) เช็กลิสต์
- [ ] ไม่มี error ใน console ตลอด 10 รอบ (รวมกดเล่นใหม่เร็ว ๆ)
- [ ] จอ 375px: ตัวหนังสือไม่ล้น ไม่ทับ ปุ่มกดง่าย
- [ ] คนใหม่ไม่ตายใน 5 วินาทีแรก · เล่นจนจบได้ในเวลาที่ตั้ง
- [ ] เกรดกระจาย: bot ปกติได้ B–A · bot ไม่ตายได้ S
- [ ] ตั้ง `GRADES` จากผลจริง · กรรมการ `max_points_per_second` ≈ (คะแนนสูงสุดแบบไม่ตาย ÷ วินาที) × 1.2

## 4) เพื่อนเล่น
ขึ้นเว็บ (`npm run ship`) → ให้เพื่อน 2 คนสแกน QR เล่น → ถาม 3 ข้อ: ยากไปไหม · ตรงไหนงง · อยากได้อะไรเพิ่ม → ปรับตัวเลขใน config.js

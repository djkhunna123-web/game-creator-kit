## ให้ภาพทั้งเกมเป็นสไตล์เดียวกัน
1. เจนตัวเอกก่อน 1 ภาพ (สไตล์ที่ผู้ใช้เลือก: พิกเซล / การ์ตูน / อนิเมะ)
2. ภาพต่อไปทุกภาพ ส่งภาพตัวเอกใน `image_urls` เป็นต้นแบบ + เขียนในพรอมต์ว่า "same art style as the reference"
3. จากภาพวาด/รูปถ่ายของผู้ใช้: `upload_reference` (แปลง png เป็น jpg ก่อน) แล้วใช้เป็นต้นแบบ
4. ห้ามเหมือนตัวละครดังที่มีลิขสิทธิ์ · รูปคนอื่นต้องได้รับอนุญาต

## วาดหน้าจอเกมก่อน แล้วสร้างตาม (เทคนิคเด่นของคลาส)
เจนภาพหน้าจอเกม 9:16 2–3 แบบ ("vertical mobile game screenshot, score top-left, ...") → ผู้ใช้เลือก 1 → จัด layout สี ฉาก ปุ่มในเกมให้ตรงภาพ → เจนชิ้นส่วนจริง (ตัวละคร ของ ฉาก) พื้นหลังใส อ้างอิงภาพที่เลือก

## ใส่เข้าเกม
- ต้นฉบับเก็บ `art-src/` · ย่อใส่ `public/assets/` (ตัวละคร ~200px png · ฉาก 720×1280 jpg q85 · เพลง mp3 ≤ 1 MB)
- ใส่ path ใน `window.ART` ด้วย key เดียวกับรูปทรงใน `makeShapes()` → ภาพแทนรูปทรงอัตโนมัติ
- จดใน `PROMPTS.md`: พรอมต์ · โมเดล · เครดิตที่ใช้จริง

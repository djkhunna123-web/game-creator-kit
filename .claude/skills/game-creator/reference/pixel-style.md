# สไตล์พิกเซล (8-bit / 16-bit / เรโทร) — ใช้คู่กับแนวเกมไหนก็ได้

ใช้เมื่อผู้ใช้พูดว่า "อยากทำเกม pixel", "ภาพ 8-bit", "แบบเกมยุคเก่า", "เรโทร"
**สไตล์ ≠ แนวเกม**: เลือกแนวจาก `genres/` ตามปกติ (วิ่ง ยิงยาน เก็บของ สร้างตึก เปิดร้าน) แล้วใช้ไฟล์นี้กำหนดหน้าตา
ตัวอย่างเกมจริง: Vibe Tower (ตึกพิกเซล 8-bit) — `genres/tower.md`

## 1 · ตั้งค่าให้พิกเซลคม (ทำก่อนใส่ภาพ)
- **อย่าตั้ง `pixelArt: true` ทั้งเกม** — จะทำให้ตัวหนังสือไทยแตกเป็นหยัก · ให้ตั้งเฉพาะภาพพิกเซลแทน:
```js
// ใน create() หลังโหลดภาพ — ทุก key ที่เป็นภาพพิกเซล
['hero', 'enemy', 'coin', 'tiles'].forEach((k) => this.textures.exists(k) && this.textures.get(k).setFilter(Phaser.Textures.FilterMode.NEAREST));
this.cameras.main.roundPixels = true;   // กันภาพสั่น/เบลอตอนเลื่อน
```
- **ขยายเป็นเลขเต็มเสมอ**: ภาพต้นฉบับขนาดพิกเซลจริง (ตัวละคร 16–48 px) แล้ว `setScale(2)` หรือ `setScale(3)` — ห้าม 2.5 (พิกเซลจะไม่เท่ากัน)
- เอฟเฟกต์ pixelfx ผ่าน `this.playFx()` ตั้ง NEAREST ให้อัตโนมัติแล้ว

## 2 · ตัวหนังสือ: อ่านง่ายก่อน "ดูเรโทร"
- ตัวหนังสือไทยทุกตัวใช้ `text()` จาก juice.js (ฟอนต์ไทยคม ≥ 15px) — **ห้ามใช้ฟอนต์พิกเซลกับภาษาไทย** อ่านยากบนมือถือ
- อยากได้ฟีลเรโทร: ใส่กรอบ/แถบ HUD เป็นพิกเซล หรือใช้ฟอนต์พิกเซลเฉพาะตัวเลขคะแนน/คำอังกฤษสั้น ๆ (ฟอนต์ต้องใช้ฟรีได้ — **ห้ามใช้ฟอนต์ Patch Pixel ของ pixelfx**)

## 3 · ภาพตัวละคร/ฉากด้วย ZenityX Studio (บอกเครดิตก่อนเจน · 3 เครดิต/ภาพ)
พรอมต์ตัวละคร (GPT Image 2.6 · 1K · `background: transparent`):
```
pixel art game sprite of [ตัวละคร], side view, full body, chunky readable pixels,
limited 16-color palette, dark 1px outline, no anti-aliasing, no text, centered, transparent background
```
- ภาพที่ได้ใหญ่ (~1024 px) — **ย่อเป็นขนาดพิกเซลจริง** ก่อนใส่เกม เช่น สูง 32 px ด้วยวิธี nearest (Python: `img.resize((w, h), Image.NEAREST)`) แล้วให้เกมขยาย ×2–×3 → พิกเซลเท่ากันทุกจุด
- ภาพต่อ ๆ ไปส่งภาพตัวเอกใน `image_urls` + "same pixel art style and palette as the reference" ให้ทั้งเกมเป็นชุดเดียวกัน
- ท่าเดิน/กระโดด: เจนชีตหลายท่าอ้างอิงตัวเอก แล้วตัดเป็นเฟรม (ดู `art.md`) · หรือทำท่าเดินง่าย ๆ จากภาพเดียว: ยกขาซ้าย/ขวาขึ้น 1 พิกเซลสลับกัน 3 เฟรม (วิธีของ Vibe Tower)
- ฉากหลัง: เจน 9:16 "pixel art background, [ฉาก], 16-color palette" → ย่อเหลือกว้าง 180 px แล้วขยาย ×2 (ฉากเลื่อนได้ใช้ 2 ภาพต่อกัน)

## 4 · สีชุดเดียวทั้งเกม (palette)
- เลือก 1 ชุดสี 8–16 สี แล้วจดใน `config.js` เช่น `PALETTE: ['#1a1c2c', '#5d275d', '#b13e53', '#ef7d57', '#ffcd75', '#a7f070', '#38b764', '#257179', '#29366f', '#3b5dc9', '#41a6f6', '#73eff7', '#f4f4f4']`
- ใช้ชุดนี้กับ: พรอมต์ภาพ ("use only these colors: …") · สีรูปทรงใน `makeShapes()` · เอฟเฟกต์ pixelfx (`--opts "{\"palette\":[…]}"` เรียงเข้ม→สว่าง)

## 5 · เอฟเฟกต์ + เสียง
- เอฟเฟกต์แบบเกม (ระเบิด เหรียญหมุน ฟันดาบ เลเวลอัป ไฟ พลุ): **pixelfx** ฟรี 244 แบบ → `pixelfx.md` (ไม่ใช้เครดิต)
- เสียง: `Sfx` ใน juice.js เป็นเสียง 8-bit อยู่แล้ว · เพลง Suno: "8-bit chiptune, upbeat, loopable, instrumental" (5 เครดิต)

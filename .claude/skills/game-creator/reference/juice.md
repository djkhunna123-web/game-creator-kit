# ความมันส์ (Game Feel) — ใช้ juice.js

หลักคิด: **ทุกการกระทำต้องมีการตอบสนอง 3 ทาง: ตา (ภาพเด้ง/ประกาย) · หู (เสียง) · มือ (สั่น/หยุดแว้บ)**
เกมที่กติกาเหมือนกัน แต่มีสิ่งนี้ = รู้สึกเป็นเกมจริง · ไม่มี = รู้สึกเหมือนการบ้าน

| เหตุการณ์ | ใส่อะไร (จาก juice.js) |
|---|---|
| ได้คะแนน | `addScore()` ในแม่แบบ = `Sfx.coin(คอมโบ)` + `Juice.burst` + `Juice.pop('+10')` + `Juice.punch(scoreText)` |
| ของหายาก | `Sfx.gold()` + `Juice.burst(…, 22)` + `Juice.flash(สีทอง)` |
| คอมโบขึ้นขั้น | `Juice.banner('COMBO ×3!')` + `Sfx.combo()` |
| พลาด/โดน | `loseLife()` = `Sfx.hit()` + `Juice.hitstop(90)` + `Juice.shake()` + `Juice.flash(แดง)` + สั่นมือถือ |
| เริ่มเกม | `Juice.countdown()` 3-2-1-GO (มีในแม่แบบ) |
| ช่วงพีค | `enterFever()` (มีในแม่แบบ) — หรือบอส / คลื่นศัตรูใหญ่ |
| ตัวละครเคลื่อนที่ | `Juice.trail(obj)` ไฟท้าย/ฝุ่น · เอียงตามทิศ · ยืด-หดตอนกระโดด/ลงพื้น |
| จบเกม | เกรด S/A/B/C เด้ง + ตัวเลขวิ่ง `Juice.countUp` (มีในแม่แบบ) |

เอฟเฟกต์ภาพแบบเกม (ระเบิด เหรียญหมุน ฟันดาบ เลเวลอัป): เพิ่มด้วย `this.playFx()` จาก pixelfx → `pixelfx.md` (ใช้คู่กับตารางนี้ ไม่ใช่แทน)

ข้อควรระวัง
- อย่าใส่จอสั่น/แฟลชกับเหตุการณ์ที่เกิดถี่มาก (ทุกเหรียญ) — ใช้กับเหตุการณ์สำคัญเท่านั้น
- ตัวเลขลอยตัวใหญ่สุด 28px · banner ไม่เกิน 1 อันต่อวินาที (ไม่งั้นทับกัน)
- `Juice.hitstop` หยุดเฉพาะ `update()` — ต้องมี `if (Juice.frozen()) return;` (แม่แบบมีแล้ว)
- เสียงเล่นได้หลังผู้เล่นแตะจอครั้งแรกเท่านั้น (`Sfx.unlock()` อยู่ในปุ่มเริ่มแล้ว)
- ทดสอบแบบเร่งเวลาจะเห็นตัวหนังสือค้าง — tween ใช้นาฬิกาจริง ไม่ใช่บั๊ก · ดูภาพให้ทดสอบด้วยความเร็วจริง
- ข้อความที่อาจถูกลบระหว่างแอนิเมชัน (เช่น กดเล่นใหม่เร็ว ๆ): juice.js กันไว้แล้ว — ถ้าเขียน tween เอง ให้เช็ก `obj.active` ก่อน `setText`

# เอาเกมขึ้น Play Store / App Store (ทำต่อเองที่บ้าน)

> ไม่อยู่ในขอบเขตคลาส 1 วัน (คลาสสอนเกมบนเว็บ) — คู่มือนี้ให้ไปทำต่อเอง
> **ทางลัดที่ใช้ได้ทันที:** ติดตั้งเกมเป็นไอคอนบนมือถือ (เกมจาก Kit ทำได้แล้ว) — Android: เมนู ⋮ → ติดตั้งแอป · iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม

## ต้องเตรียมอะไร
| | Google Play | App Store |
|---|---|---|
| บัญชีนักพัฒนา | 25 USD ครั้งเดียว | 99 USD ต่อปี |
| เครื่องที่ใช้ทำ | Windows หรือ Mac + Android Studio | **ต้องมี Mac** + Xcode |
| บัญชีใหม่ (บุคคล) | ต้องให้คนทดสอบ ≥ 12 คน นาน 14 วันก่อนเปิดจริง | — |
| เวลาตรวจ | ไม่กี่วัน | 1–3 วัน (ถูกตีกลับบ่อยถ้าแอปดู "เหมือนเว็บ") |
| เอกสาร | นโยบายความเป็นส่วนตัว (ลิงก์) · ภาพหน้าจอ · ไอคอน 512px · คำอธิบาย | เหมือนกัน + ข้อมูลความเป็นส่วนตัวละเอียดกว่า |

## ขั้นตอน (ให้ AI ช่วยได้ทุกขั้น)
1. **ห่อเกมเว็บเป็นแอป** ด้วย Capacitor:
   ```
   ช่วยห่อเกมนี้เป็นแอปมือถือด้วย Capacitor (Android ก่อน)
   ใช้ไฟล์ใน public/ + index.html · เปิดเต็มจอ · ล็อกทิศจอตาม ORIENTATION ใน config.js (แนวตั้ง/แนวนอน) · ไอคอนจาก public/icons
   ```
2. **Android**: เปิดใน Android Studio → ลองบนมือถือจริง → Build → Generate Signed Bundle (.aab) → อัปโหลดใน Play Console
3. **iPhone**: เปิดใน Xcode บน Mac → ใส่ Apple Developer Team → ลองบนเครื่อง → Archive → อัปโหลด App Store Connect
4. ทำหน้า **นโยบายความเป็นส่วนตัว** (บอก AI ให้ทำเป็นหน้าเว็บในเกม `/privacy`)
5. ภาพหน้าจอ: ให้ AI แคปจอเกมขนาดที่ Store ต้องการ

## ข้อควรระวัง
- ขายของในแอป: Store บังคับใช้ระบบจ่ายเงินของ Store (In-App Purchase) — Stripe ในเกมเว็บใช้ในแอปไม่ได้ตรง ๆ
- ตารางคะแนน Supabase ใช้ต่อได้เหมือนเดิม
- ภาพ/เพลงต้องเป็นของคุณเองหรือมีสิทธิ์ใช้ (ภาพจาก ZenityX Studio ใช้ได้) · ห้ามคล้ายเกม/ตัวละครดัง
